# 골판지 전기 폭 부스트 한글 패치

**Danball Senki Baku Boost (ダンボール戦機 爆ブースト)** 3DS 비공식 한글 패치입니다.

> 이 저장소에는 **게임 롬이 들어 있지 않습니다.** 본인이 소유한 게임에서 직접 추출한 원본 롬에 적용하는 xdelta 패치만 배포합니다.

## 현재 버전

**v1.46** — [Releases](../../releases)에서 받을 수 있습니다.

## 한글화 범위

- 스토리·필드 대사, 이벤트 컷신 자막, 영상 자막
- 메뉴, 아이템·파츠·무기 설명, 메일, 퀘스트 기록, 시스템 메시지
- 전투 음성 자막, LBX 등장 자막 등 그림으로 된 글자
- 고유명사는 애니메이션 한국어판 표기를 따랐습니다. (예: 겟코마루, 바르도마, 비빈버드, 매드독)

**일본어로 남겨 둔 부분**

- 가나 키보드, あ행 탭, 가나 비밀번호: 입력 방식이 일본어 기준이라 그대로 두었습니다.
- 가게 간판, 배경에 그려진 글자

## 필요한 원본

| 항목 | 내용 |
|---|---|
| 파일 | `Danball Senki Baku Boost (Japan) (Rev 1).3ds` |

다른 판(Rev 0, 암호화된 롬, 트리밍된 롬)에는 적용되지 않습니다.

## 적용 방법

### 1. 원클릭 (Windows)
1. 릴리스 압축 파일을 원본 롬이 있는 폴더에 풉니다.
2. `apply-patch.bat`을 실행합니다.
3. 같은 폴더에 `Danball-KO-v1.46.3ds`가 만들어집니다.

### 2. xdelta UI / Delta Patcher
- 패치 파일: `Danball-Senki-Baku-Boost-KO-v1.46.xdelta`
- 원본 파일: 위의 원본 `.3ds`
- 출력 파일 이름을 정하고 적용합니다.

### 3. 명령줄
```
xdelta3.exe -d -s "원본.3ds" Danball-Senki-Baku-Boost-KO-v1.46.xdelta "Danball-KO.3ds"
```

결과 롬 SHA-256: `6DD547A38CDF1A814946DCD9DAC1D2A17386AD6543B715350625EC81D8D511EA`

## 에뮬레이터 설정 (Azahar / Citra)

기본 설정 그대로 플레이할 수 있습니다.

1. **오디오 에뮬레이션: HLE (기본값)** — LLE로 두면 공격을 맞을 때마다 전투가 크게 느려집니다.
2. **비동기 셰이더 컴파일: 켜기 (권장)** — 전투 초반의 끊김이 줄어듭니다.

패치된 롬을 쓸 때는 예전 한글 모드 폴더(`load/mods/0004000000078500`)를 같이 켜 두지 마세요.

## 면책

이 프로젝트는 팬이 만든 비공식 번역이며, LEVEL-5 및 관련 권리자와 아무런 관계가 없습니다.
게임의 모든 권리는 원 저작권자에게 있습니다. 롬 파일은 배포하지 않으며, 요청에도 응하지 않습니다.
